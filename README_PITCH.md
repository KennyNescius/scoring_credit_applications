# WindAI Scoring Engine
**Питч-презентация для жюри CBU Coding Hackathon 2026**

## 1. Проблематика (Что мы решаем?)
Банки и микрофинансовые организации часто сталкиваются с двумя проблемами:
1. **Эффект "черного ящика"**: AI-модели выдают скор, но ни клиент, ни кредитный менеджер не понимают, *почему* произошел отказ.
2. **Упущенная выгода**: Если клиент просит 50 млн, а проходит только на 30 млн, обычные системы дают отказ. Мы теряем клиента.

## 2. Решение (WindAI)
Мы разработали **Explainable AI (XAI) Scoring Engine** — прозрачную систему принятия кредитных решений, которая:
- **Объясняет решения**: Выводит ТОП-факторы "человеческим" языком (на узбекском и русском), объясняя клиенту причину отказа (например, "Текущая долговая нагрузка слишком высока").
- **Оптимизирует лимиты**: Если клиент не проходит на запрашиваемую сумму, алгоритм *Binary Search* за миллисекунды высчитывает **максимально возможный лимит**, чтобы не потерять клиента.
- **Предоставляет песочницу (What-If)**: Андеррайтеры могут менять параметры клиента "на лету" и смотреть, как меняется риск (PD) и балл.

## 3. Техническая архитектура и ML
Мы не использовали готовые тяжелые фреймворки. Наша модель — это интерпретируемая **Логистическая регрессия (Scorecard)** со следующими фичами:
- **Feature Engineering**: Cash-flow анализ по транзакциям, расчет медианного дохода, коэффициента вариации (CV) для оценки стабильности дохода.
- **Target Encoding & Winsorization**: Очистка выбросов (1-99 перцентили) и кодирование профессий/целей по историческому уровню дефолта (вместо жесткого One-Hot Encoding).
- **Lightweight Backend**: Flask (Python) без базы данных для скорости MVP, полная обработка DataFrame в памяти.

## 4. Оценка по критериям Хакатона
| Критерий | Как реализовано |
| :--- | :--- |
| **Бизнес-ценность** | Снижение % отказов за счет предложения альтернативного лимита. Повышение лояльности клиентов за счет понятных причин. |
| **Сложность алгоритмов** | O(30 × N) бинарный поиск лимита, Target Encoding, динамическое вычисление Scorecard баллов (PDO). |
| **Интерфейс (UX/UI)** | Современный дашборд, дабл-язычность (Ru/Uz), интерактивная увеличиваемая схема ERD, графики Chart.js. |
| **Готовность (MVP)** | 100% работоспособный код. 8 полноценных экранов. Внедрена локализация `session`-стейтом. |

## 5. Вау-эффекты (Обязательно покажите жюри!)
1. **Переключение языков**: Кликните Ru/Uz на любой странице — XAI-движок моментально переведет даже генеративные причины отказов.
2. **What-If Симулятор**: Измените зарплату клиента и покажите, как пересчитывается скоринговый балл в реальном времени без перезагрузки.
3. **Модуль Андеррайтера**: Покажите таблицу с цветовой индикацией рисков (DTI > 50% светится красным).
4. **Схема ERD**: Продемонстрируйте интерактивную схему архитектуры с зумом и встроенным словарем факторов (Data Dictionary).
